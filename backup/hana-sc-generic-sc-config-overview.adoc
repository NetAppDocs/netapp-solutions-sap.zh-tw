= 了解如何為 SAP HANA 環境配置SnapCenter
:allow-uri-read: 


[role="lead"]
使用兩階段方法為 SAP HANA 環境配置SnapCenter ：對共享資源（憑證、儲存系統和政策）進行初始配置，對各個 HANA 系統進行特定於資源的配置（主機部署、自動發現和保護設定）。

對於具有多個 HANA 系統的 SAP HANA 環境， SnapCenter配置可以分為兩個主要部分：

* 初始配置
+
** 憑證、儲存和策略配置。+ 這些設定或資源通常被多個 HANA 系統使用。


* HANA資源特定配置
+
** 主機、HANA 和資源保護配置必須針對每個 HANA 系統單獨進行。
