= NetApp SAP 解決方案有哪些新特性
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
了解 SAP 解決方案的新功能。



== 2026 年 2 月 26 日

更新 https://docs.netapp.com/us-en/netapp-solutions-sap/lifecycle/sc-copy-clone-introduction.html["利用SnapCenter 功能實現SAP HANA系統複製與複製作業自動化"]解決方案以涵蓋使用本機安全儲存（LSS）進行 SAP HANA 磁碟區加密。

更新 https://docs.netapp.com/us-en/netapp-solutions-sap/backup/hana-sc-generic-scope.html["SAP HANA利用SnapCenter 功能進行備份與還原"]解決方案以涵蓋使用本機安全儲存區（LSS）的 SAP HANA Volume 加密，以及新的支援組態。



== 2025年12月2日

新方案：link:https://docs.netapp.com/us-en/netapp-solutions-sap/backup/hana-sc-generic-scope.html["SAP HANA利用SnapCenter NetApp備份與還原"^]

該解決方案提供了使用NetApp SnapCenter進行 SAP HANA 資料保護的最佳實踐，涵蓋了SnapCenter配置和操作指南，用於保護ONTAP AFF和ASA系統、 Azure NetApp Files和Amazon FSx for ONTAP上的 SAP HANA 系統。



== 2025年11月12日

新方案link:https://docs.netapp.com/us-en/netapp-solutions-sap/bp/kvm-hana-introduction.html["SAP HANA 與 SUSE KVM 和NetApp存儲"^]：

使用具有 SR-IOV 網路介面和 NFS 或 FCP 儲存存取的NetApp存儲，在 SUSE KVM 上部署 SAP HANA 單主機。
