= 使用 SR-IOV 和 NFS 在 SUSE KVM 上部署 SAP HANA，並使用NetApp儲存。
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
使用具有 SR-IOV 網路介面和 NFS 或 FCP 儲存存取的NetApp存儲，在 SUSE KVM 上部署 SAP HANA 單主機。請按照此工作流程配置虛擬接口，將其指派給虛擬機，並設定儲存連接以獲得最佳效能。

有關 SAP HANA on KVM 虛擬化的概述，請參閱 SUSE 文件： https://documentation.suse.com/sbp/sap-15/html/SBP-SLES4SAP-HANAonKVM-SLES15SP7/["SUSE 在 KVM 上部署 SAP HANA 的最佳實踐"]。

image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]link:kvm-hana-requirements.html["查看配置要求"]

[role="quick-margin-para"]
審查在 SUSE KVM 上使用NetApp儲存、SR-IOV 和儲存協定部署 SAP HANA 的關鍵要求。

image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]link:kvm-hana-network.html["配置SR-IOV網路介面"]

[role="quick-margin-para"]
在 KVM 主機上設定 SR-IOV（單一 I/O 虛擬化），並為 VM 指派虛擬介面以進行網路通訊和儲存存取。

image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:kvm-hana-fcn.html["配置光纖通道網路"]

[role="quick-margin-para"]
將實體 FCP HBA 連接埠指派給 VM 作為 PCI 設備，以便在 SAP HANA 中使用 FCP LUN。

image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"]link:kvm-hana-storage.html["配置用於 SAP HANA 的NetApp存儲"]

[role="quick-margin-para"]
在虛擬機器和NetApp儲存系統之間建立 NFS 或 FCP 儲存連接，用於 SAP HANA 資料庫檔案。
