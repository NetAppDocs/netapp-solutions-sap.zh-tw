下圖呈現所使用實驗室設定的高階總覽。使用兩套單主機 HANA MDC 系統來示範各種操作。HANA 系統 BM1 用於執行備份、還原和恢復作業，而 HANA 系統 QM1 則作為 SAP System Refresh 作業的目標系統。HANA 系統部署在兩台裸機伺服器上，儲存設備端則使用兩個 ASA A30 雙節點叢集。第一個叢集承載 HANA 系統的所有儲存設備單元，第二個叢集則用作備份複寫的目標。
